# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work.
Harassment or personal attacks are not tolerated.

To report a problem, contact the maintainer privately through
[GitHub](https://github.com/oliverxuzy-ai). Reports are handled confidentially.
