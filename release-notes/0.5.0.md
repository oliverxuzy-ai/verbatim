**会议结束自动停止录音**（默认开启）
- 忘了点结束也没关系：会议看起来结束后，胶囊顶部出现 60 秒倒计时，同时弹出通知。点倒计时或通知里的「Keep recording」就继续录；倒计时期间有人说话也会自动取消。
- 什么时候算结束：对方声音安静 3 分钟、你也 2 分钟没说话（日历时间已过时，会后在屋里聊天不算）；或者 10 分钟谁都没说话（还没人开口时 20 分钟，比如在等候室）。线下会议同样适用。
- 「说话」以识别出文字为准，空调、风扇、键盘声不会让录音一直开着。
- 停下后照常保存，并提示是自动停止的。不想要可以在「设置 → Calendar → One-click start」里关掉。

**修复：精修不再频繁失败**
- 以前长会议和几乎所有中文会议，精修常常提示「The refined transcript missed speech that the live one caught」，只能保留实时版本。
- 现在精修漏掉的几句会从实时转写补回来，精修照常完成。只有漏掉的内容很多（超过实时转写的 15%）时才保留实时版本。
- 中文按字比对，不再因为没有空格把整句当成一个词。

安装：下载 `Verbatim-0.5.0.dmg`，拖进 Applications 覆盖旧版。需要 macOS 26。
