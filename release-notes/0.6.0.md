**新功能：自动更新**
- Verbatim 每 6 小时查一次 GitHub 上的新版本，有新版就在后台下载并校验。等你没在录音、没在整理稿子、没有会议正在开，也没在用它的时候，它会自己重启成新版。录音和设置都会保留。
- 菜单栏底部出现「Update to x」时，点一下就能马上更新。
- 在「Settings → General → Updates」里可以关掉自动更新，或者点「Check now」手动检查。
- 需要 Verbatim 放在「应用程序」文件夹里才能自己更新。

**新功能：会议结束后可以继续录**
- 会议提前停了（手动停，或者被自动停止），可以接着录。新内容接在同一份逐字稿和录音后面，中间没录的那段不计入时长，逐字稿里会标出从哪里继续。
- 入口在会议页顶部、菜单栏（2 小时内停的会议），以及自动停止的提示和通知里。
- 再次停止后会对整场会议重新精修，说话人会合并到一起。

**修复：录音时崩溃或卡死不再丢逐字稿**
- 识别出的每一句都会立刻写进硬盘，录音每 5 秒自动保存一次。
- 万一 Verbatim 在录音时崩溃、被强制退出或卡死，下次打开会自动恢复这场会议，并提示用「Refine」从录音里补全。

安装：下载 `Verbatim-0.6.0.dmg`，拖进 Applications 覆盖旧版。需要 macOS 26。这是最后一次需要手动安装，之后的版本会自动更新。
